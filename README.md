# Roblox ESP Script with GUI

This project contains scripts for an ESP (Extra Sensory Perception) system in Roblox, including a GUI for customization. The ESP script creates indicators for all players in the game, showing their names and changing the color based on their health status. The GUI script provides a user interface with a color picker and sliders to adjust the size of the ESP indicators.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the `ServerScriptService` and create a new Script. Name it `ESP` and paste the contents of `ESP.lua`.
4. Navigate to the `StarterPlayerScripts` and create a new Script. Name it `GUI` and paste the contents of `GUI.lua`.

## Use

1. Play the game to see the ESP indicators.
2. Use the GUI to customize the ESP settings:
   - Enter RGB values in the color picker to change the ESP indicator color.
   - Adjust the slider to change the size of the ESP indicators.
   - Click the "Apply" button to apply the changes.
